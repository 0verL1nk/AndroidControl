# UI/UX 设计规范：远程协助长辈手机

**版本**：v1（M1 基线） · **适用**：`agent/`（长辈端，极简）+ `controller/`（控制端，功能密集）
**依据**：README、spec.md、plan.md、data-model.md、ROADMAP.md
**硬约束**：长辈端正文字号 ≥20sp、点击目标 ≥56dp、WCAG AA、深浅双主题；控制端 Material 3。

---

## 1. 设计原则

1. **长辈端用眼睛读，不用脑子读**。颜色 + 大图标 + 大字三件套同时表达状态；任何一屏第一眼
   结论 ≤1 秒可得。文案写"人话"（"网络没连上"），绝不出现错误码、端口、日志。
2. **被协助必须被看见，且只惊扰一次**。会话开始播一次显著入场提示（横幅 + 轻振动），之后收敛为
   常驻状态条——`正在被协助` 大字 + 结束按钮始终可见，不遮挡长辈在看的内容，不重复弹窗/发声。
3. **越权/破坏性操作必须慢半拍**。控制端"断开"、长辈端"结束"都要二次确认；误触不产生不可逆后果。
   安全边界（正在控制谁的手机）在操控页常驻可见。
4. **弱网不装死**。画面卡住必须明说正在发生什么（"正在重连 3/15"），用**可数进度**替代无限转圈。
5. **两套 App 是两种性格**。长辈端 = 一张会变色的状态卡（零层级、零导航）；控制端 = 工具台
   （高密度、可折叠、可全屏）。共享令牌，但密度与字号按场景分流。
6. **失败路径与成功路径同等设计**。每屏定义空态/加载/失败/极端长文本；失败时给"唯一可执行的
   下一步"，绝不留无法退出的死角。

### 2.4 间距 / 圆角 / 阴影 / 动效
- **间距**：`4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 · 64`(dp)。安全边距：长辈端 24dp、控制端 16dp。
- **圆角**：`sm=8 · md=12 · lg=16 · xl=24 · pill=999`。长辈端卡片 `lg`，主按钮 `pill`。
- **阴影**：`e1=1dp · e2=3dp · e3=6dp · e4=8dp`。控制端悬浮条 `e4`，长辈端状态卡 `e1`。
- **遮罩**：全屏对话框 `#000` 40%（浅）/ 60%（深）。
- **时长**：`instant=90 · fast=150 · standard=220 · medium=300 · slow=400`(ms)。
- **曲线**：`standard=(0.2,0,0,1) · emphasized=(0.05,0.7,0.1,1) · decelerate=(0,0,0,1) · accelerate=(0.3,0,1,1)`。
- **规则**：父级变色=淡变(220,standard)；横幅=下滑入(300,emphasized)；按压=缩放0.97+涟漪(90,instant)。
  越权/结束类确认用 `emphasized`。开启系统"减少动画"时全部降为瞬时。

## 3. 长辈端 · 主状态页（唯一主屏）

**用途**：一眼看懂"是否可被协助 / 正在被协助 / 出错"；必要时一键结束。零导航、零滚动。
骨架四态共用：大图标（上）+ 状态大字（中）+ 一句人话 + 一个主操作（下）。

```
┌──────────────────────────────┐
│           ╭────╮             │  状态图标 96dp（圆底 160dp）
│          │  🛡️  │            │
│           ╰────╯             │
│        已准备好协助           │  display 44sp
│   家人现在可以连接这台手机     │  bodyLarge 22sp
│   ┌────────────────────┐     │  主按钮 高 64dp（目标 ≥56dp）
│   │     结束协助 / 关闭   │     │
│   └────────────────────┘     │
└──────────────────────────────┘
```

### 状态 × 内容映射
| 状态 | 触发(data-model) | 图标 | 颜色 | 大字 | 说明 | 主操作 |
|---|---|---|---|---|---|---|
| **就绪** | `IDLE`+引擎已起 | 盾牌✅ | success | 已准备好协助 | 家人现在可以连接这台手机 | "关闭协助"(次要) |
| **准备中** | 启动流程中 | 旋转环 | neutral | 正在准备… | 请稍候，不要关机 | 无(禁用) |
| **被协助** | `PAIRING`/`ACTIVE` | 屏幕共享👁 | info | 正在被协助 | **王芳**正在看你的手机 | "结束"(danger) |
| **出错** | `fail()`/断网 | ⚠️ | danger | (人话标题) | 一句原因 + 下一步 | "重试" |

被协助态额外显示已连接时长（`00:03:17`，title 24sp）；结束后回就绪态并提示"已结束协助"
（success，1.5s 隐去）。

### 出错文案（禁止错误码）
| 底层 reason | 大字 | 说明 | 唯一下一步 |
|---|---|---|---|
| 无网络/Shizuku 掉线 | 网络没连上 | 请检查家里的 Wi-Fi 路由器 | "重试"；连续 3 次失败→"请联系家人" |
| 引擎启动失败 | 协助暂时用不了 | 可能是系统更新了，需要家人重新设置一次 | "知道了"(收起) |
| 授权被拒 | 还没有获得权限 | 需要家人帮忙设置一次 | "知道了" |
| 版本不匹配 | 需要更新 | 请让家人更新这台手机上的 App | "知道了" |

### 元素清单
| 元素 | 尺寸 | 字号 |
|---|---|---|
| 状态图标 | 96dp 图标 / 160dp 圆底（container 色） | — |
| 状态大字 | 单行自适应，≤2 行 | `display` 44sp |
| 说明文字 | 屏宽 − 48dp，≤3 行 | `bodyLarge` 22sp |
| 主按钮 | 高 64dp，宽 ≥240dp，pill | `label` 20sp |
| 被协助状态条 | 高 56dp，撑满顶部，info 填充白字 | `title` 24sp |

### 交互与动效
- 状态切换：底色/图标 220ms `standard` 淡变，大字同步；不做花哨转场。
- 会话开始：一次性 300ms 下滑横幅 + 一次 200ms 短振动（CONFIRM），之后不重复；结束不振动。
- "结束"：点击→二次确认(§5)→立即停采集→1.5s success 提示后回就绪。

## 4. 长辈端 · 隐藏诊断入口（"高级信息"）

**入口**：连点标题正上方不可见热区 88×88dp **7 次**；第 5 次起每次轻振动"快了"，第 7 次打开。
部署者可经 intent 直接打开。**主界面永不出现**端口/口令/日志。

│ ─────────────────────────────│

│  控制端口 27185 / 视频 27186   │
│  口令    482913   [复制]       │  6 位；点整行复制
│  最近连接（20 条）             │

## 5. 长辈端 · "结束协助"二次确认

**目的**：防误触，但**不**让长辈在真需要时找不到出口，故默认焦点高亮"结束"。

```

│  结束后家人将看不到你的手机     │  bodyLarge 22sp
│  ┌──────────┐ ┌───────────┐  │  两按钮高 64dp
│  │   取消    │ │   结束     │  │  "结束" danger 填充
│  └──────────┘ └───────────┘  │
└──────────────────────────────┘
```
遮罩 40%；点遮罩=取消；点"结束"立即生效。

## 6. 控制端 · 连接页（设备列表 + 手动输入）

**用途**：选已绑定设备或手输地址/口令连接。为**多设备**留位（M5 多位长辈）。

```
┌──────────────────────────────────────┐
│  远程协助                    [⚙]      │  headline 32sp
│  ┌──────────────────────────────────┐ │
│  │ 爸爸的手机            ● 在线      │ │  设备卡 高 88dp
│  │ 最近使用 20 分钟前                │ │  caption 16sp
│  └──────────────────────────────────┘ │
│  ┌──────────────────────────────────┐ │
│  │ 妈妈的老手机          ○ 离线      │ │  灰化，仍可点(触发重试)
│  └──────────────────────────────────┘ │
│  ▸ 手动输入地址 / 口令            ▾   │  折叠行
│    地址 10.66.66.3:27185  口令 ••••••  │  展开后输入框
│    ┌────────────────┐                 │
│    │     连接        │                 │
│    └────────────────┘                 │
└──────────────────────────────────────┘
```

### 状态
- **空态**（无绑定）：居中大图标 + "还没有绑定设备" + 唯一操作"查看部署步骤"；仍保留"手动输入"。
- **加载**（探测在线）：设备卡骨架 + 顶部细进度条（不确定态，<2s 完成）。
- **连接中**：目标卡 pressing + 全屏遮罩"正在连接 爸爸的手机…" + 取消；>10s 显示"仍在尝试…"，30s 超时转失败。
- **失败**：明确区分原因，主按钮"重试"，次按钮"返回"。
- **极端长文本**：设备名 ≥20 字截断一行 + 省略号（长按看全名）；地址过长中间省略。

### 失败态文案
| 原因 | 标题 | 说明 | 主操作 |
|---|---|---|---|
| 设备离线 | 爸爸的手机离线 | 手机可能关机或没连网 | 重试 / 返回 |
| 未被授权 | 无法连接这台设备 | 需要对方在你手机上确认绑定 | 返回 / 帮助 |
| 版本不匹配 | 两端版本不一致 | 请把两端 App 更新到同一版本 | 返回 |
| 口令错误 | 口令不正确 | 请核对手机上的 6 位口令 | 返回输入 |

### 动效
设备卡点击=涟漪 90ms；连接遮罩淡入 220ms；失败卡 300ms 从下淡入 `emphasized`；列表增删
220ms 位移淡变（为多设备预留）。

## 7. 控制端 · 操控页（全屏视频 + 悬浮操作条）

**用途**：看并操作长辈手机。横屏优先、可全屏、边缘手势需与系统返回协调。

### 7.1 布局
```
横屏（默认推荐）
┌─────────────────────────────────────────────────┐
│ ⓘ 正在控制 爸爸的手机 ▪20fps ▪78ms  [隐藏浮层] │ 顶部安全条 高 40dp
├─────────────────────────────────────────────────┤
│              长辈手机画面（等比 letterbox）       │ 触摸区=可操作区
├─────────────────────────────────────────────────┤
│ [←返回][◉主页][▢最近] [🔈][🔉] [🔓锁定] [⏻断开] │ 悬浮条 高 64dp
└─────────────────────────────────────────────────┘
竖屏：安全条 / 画面(等比) / 同一悬浮条，纵向堆叠。
```

### 7.2 元素清单
| 元素 | 尺寸 | 备注 |
|---|---|---|
| 顶部安全条 | 高 40dp，`surfaceHigh` 90% | 常驻，显示"正在控制 XX 的手机" |
| 悬浮操作条 | 高 64dp，`e4`，居中 | 3s 无操作淡出，点画面唤回 |
| 返回/主页/最近 | 56×56dp，图标 28dp | 转发 KEYCODE_BACK/HOME/APP_SWITCH |
| 音量加/减 | 56×56dp | 转发音量键 |
| 锁定 | 56×56dp | 切"仅观看"，屏蔽画面触摸防误触 |
| 断开 | 56×56dp，danger 描边 | 破坏性→二次确认(§7.5) |
| 状态浮层 | §7.3 | 可一键隐藏 |

### 7.3 状态浮层（性能 HUD）
```
┌───────────────────────────────┐
│ 帧率 21.4 fps   延迟 78 ms     │  micro/caption，半透明黑底白字
│ 码率 1.9 Mbps   ▓▓▓▓░ 良好     │  质量条 5 格
└───────────────────────────────┘
```
右上角，距安全条 8dp。默认显示，点顶部"[隐藏浮层]"或下滑隐藏并记忆。质量分级
优秀(≤120ms)/良好(≤250)/一般(≤400)/较差(>400)，用**文字+格数**双重编码不靠色。刷新 1Hz。

### 7.4 弱网 / 重连（恢复态）
画面卡住**立即**覆盖半透明遮罩，明确进度，绝不放任冻结画面假装正常：
```
┌───────────────────────────────┐
│          ⟳ (旋转环)            │
│     正在重连…（3/15）          │  headline 32sp
│   网络不稳定，请稍候，无需操作   │  body 20sp
│         [ 断开 ]               │  次要，可退出
└───────────────────────────────┘
```
计数来自 FR-012 重连逻辑（≤20s）。超过 15 次→"无法恢复"失败态（"连接已中断 / 长辈端可能
已离线"，主操作"重新连接 / 返回"）。

### 7.5 断开二次确认
```
┌───────────────────────────────┐
│     要断开连接吗？              │
│  断开后将无法继续操作对方手机    │
│  ┌──────────┐ ┌────────────┐  │
│  │   取消    │ │   断开      │  │  danger 填充
│  └──────────┘ └────────────┘  │
└───────────────────────────────┘
```
遮罩 40%，点遮罩=取消。断开键与其余键间距 ≥24dp 防误触。

### 7.6 手势与系统冲突
- 操控页请求沉浸式（隐藏系统栏）；左右边缘滑动**默认转发为长辈端返回手势**。为免被本机系统
  返回手势拦截，对左右边缘划出**系统手势排除区**（gesture exclusion）；设备不支持时回退到
  "仅靠操作条返回键"。取舍见 §9。
- 长按=转发长按(>500ms)；双指手势 M1 不转发，仅提示"暂不支持双指缩放"。

### 7.7 不可控状态（须与"在线可操作"明确区分）
| 状态 | 表现 | 区别于 |
|---|---|---|
| 长辈端离线 | 灰化占位 + "设备已离线，不再重试" | "重连中"：**无旋转环、无计数** |
| 被对方结束 | "对方已结束协助" + "重新请求连接" | 断网：**不再自动重连** |
| 安全窗口黑屏 | 黑屏 + 角标"此页面受系统保护，无法显示" | 系统行为，非故障 |
| 版本不匹配 | 连接前拦截，不进操控页 | — |

### 7.8 动效
进入：画面 220ms 淡入，操作条 300ms 下滑入，2s 后自动淡出。触摸本地按下即高亮 90ms（不等
远端回显）以降低感知延迟。浮层数值滚动 220ms，质量条 300ms。重连遮罩 220ms 淡入。

## 8. 无障碍与适老专章

- **对比度**：正文 ≥4.5:1，长辈端大字/图标 ≥7:1（§2 已标注）；图形/描边/状态点 ≥3:1。深色下
  正文避免纯白 `#FFF`（用 `#E3E2E6` 降眩光）。
- **字号与缩放**：长辈端可见文字 ≥20sp，系统放大至 1.3× 不截断（大字可降到 36sp 换行，仍 ≥20sp）；
  控制端正文 ≥16sp。行宽 ≤~30 汉字。
- **点击目标**：长辈端 ≥56dp（主按钮 64dp），控制端 ≥48dp（操作条键 56dp）；间距长辈端 ≥16dp、
  控制端 ≥8dp，防胖手指误触相邻键。
- **单手可达**：长辈端主操作/结束按钮置于屏幕下半部 60% 区域。
- **TalkBack 朗读文案**（示例）：
  | 元素 | 朗读 |
  |---|---|
  | 就绪图标 | "状态：已准备好协助。家人现在可以连接这台手机" |
  | 被协助状态条 | "正在被协助。王芳正在看你的手机。双击可结束" |
  | 结束按钮 | "结束协助，按钮" |
  | 出错卡 | "网络没连上。请检查家里的 Wi-Fi 路由器。重试，按钮" |
  | 控制端设备卡 | "爸爸的手机，在线，最近使用 20 分钟前。双击连接" |
  | 状态浮层 | "帧率 21 帧，延迟 78 毫秒，连接质量良好" |
  | 重连遮罩 | "正在重连，第 3 次，共 15 次" |
  状态变化用 `liveRegion=polite`，错误用 assertive；装饰图标 `contentDescription=null`，语义由
  容器承载。
- **色盲友好**：禁止仅靠颜色——就绪=盾牌+绿、被协助=眼睛+蓝、出错=三角+红、弱网=断线图标+琥珀，
  形状各异，灰度可辨；质量条含格数与文字。success 与 danger 明度差 >30%。
- **其他**：支持"减少动画"（降瞬时）与"高对比度文本"（描边加粗）；长辈端不依赖声音（视觉冗余）。

## 9. 不确定 / 需产品决策

1. **长辈端是否加"一键求助"主动呼叫子女？** ROADMAP 列 M4。若加，主状态页需第三个主操作 + 对
   子女的推送通道；本规范暂留中央大按钮位。**需产品决策。**
2. **多控制端抢占语义未定**（spec：后到者被拒还是抢占）。影响连接页与长辈端文案（"已有另一台
   设备在协助"）。**需产品决策。**
3. **操控页边缘手势策略**：优先本机系统手势（省心、牺牲远端返回）还是优先远端（贴近真机、与本机
   冲突）。建议默认前者 + 操作条返回键；需实测各家 ROM 手势排除 API 后定稿。**待定。**
4. **会话中长辈端提示形态**：本规范用"顶部常驻条 + 一次性横幅"。是否显示对方正在操作的具体位置
   （红点指示）涉及隐私与成本。**待定。**
5. **"安全窗口黑屏"措辞**：明说"此页面受系统保护"还是笼统"暂时无法显示"，取决于长辈对"银行/
   支付"字样的心理接受度。**待定。**
6. **口令呈现**：隐藏面板 6 位口令长期固定（便于部署）还是每次会话随机（当前代码为随机）。影响
   连接页"手动输入"的心智。**需产品决策。**
7. **深浅色默认**：长辈端建议默认浅色、跟随系统；是否强制锁浅色 **待定**。
