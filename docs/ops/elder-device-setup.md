# 长辈手机一次性部署手册

**目标**：把一台 Android 手机变成"家人可以远程协助"的设备。
**执行者**：子女（或任何懂一点技术的人）。**长辈全程不需要参与。**

整个部署只做一次。之后长辈只需要在需要帮助时**打开 App**（甚至开机自启），
打开一次 App，它会自动待命——之后不需要再按任何按钮。

---

## 0. 准备

| 项 | 要求 |
|---|---|
| 手机 | Android 8.0+，**建议高通芯片**（联发科机型有已知兼容问题，见 §6） |
| 网络 | 家里 Wi-Fi，长期在线 |
| 电源 | 长期插电（设置里开"充电时保持唤醒"） |
| 电脑 | 可选。只在"用 adb 启动 Shizuku"时需要；不用电脑也能通过手机上的无线调试完成 |
| 已签名的 APK | `app-debug.apk`（同一个安装包也是控制端） |
| Shizuku APK | **13.5.4**（不要 13.6.0，原因见 §6） |

---

## 1. 打开开发者选项

设置 → 关于手机 → 连续点击"版本号" 7 次 → 返回设置 → 系统 → 开发者选项。

按品牌补充：

| 品牌 | 必开项 |
|---|---|
| 小米 / 红米（HyperOS） | **USB 调试**、**USB 调试（安全设置）**、**通过 USB 安装** |
| OPPO / 一加 / realme | **USB 调试**，并**关闭"权限监控"** |
| vivo / iQOO | **USB 调试**，开启"强制将活动设为可调整大小" |
| 华为 / 荣耀 | **USB 调试**，开启"仅充电模式下允许 ADB 调试" |
| 三星 / Pixel | **USB 调试**即可 |

---

## 2. 安装 Shizuku（版本必须是 13.5.4）

1. 把 `shizuku-13.5.4.apk` 传到手机并安装（小米可能要求指纹确认，正常）。
2. 打开 Shizuku。

> **为什么锁 13.5.4**：13.6.0 在**联发科机型**上启动用户服务会直接崩溃
> （`LoadedApk.makeApplicationInner` NPE，上游 issue #1198/#1171）。本项目依赖的正是
> 用户服务，所以必须用 13.5.4。详见 `docs/DECISIONS.md` ADR-014。

---

## 3. 启动 Shizuku

两条路，任选其一：

### A. 无线调试启动（推荐，不需要电脑）

1. 开发者选项 → **无线调试** → 打开。
2. 回到 Shizuku → 点"通过无线调试启动" → 按它的分步骤指南操作
   （点"配对"→ 输入通知栏里的 6 位配对码 → 回来点"启动"）。
3. 成功后 Shizuku 首页显示"正在运行"。

> 小米手机需要把通知样式改成"原生样式"才能看到输入配对码的入口。

### B. 用电脑启动（一次）

```bash
# 手机连上电脑并允许调试后
adb shell /data/app/<...>/moe.shizuku.privileged.api-<...>/lib/arm64/libshizuku.so
```

具体路径以 Shizuku 应用内"通过连接电脑启动 → 查看指令"显示的为准。

> 注意：**非 root 的 Shizuku 在设备重启后不会自动运行**。要在重启后恢复，需要
> 保持"无线调试"开启，并让 Shizuku 借助它自启（部分 ROM 支持；需在目标机型上实测）。
> 这属于部署后的保活问题，见 `docs/ROADMAP.md` M2。

---

## 4. 安装 App（同一个包，两种角色）

```bash
adb install -r app-debug.apk
```

或直接把 APK 传到手机上点安装。首页会显示这台手机自己的 6 位配对码，
打开即处于待命状态，不需要按"开启"。

安装后打开 App，它会请求：
- **通知权限**：允许（用于显示"正在被协助"的常驻通知）
- **Shizuku 授权**：出现"要允许长辈端使用 Shizuku 吗"时选 **始终允许**
- **显示在其他应用上层**：允许（被协助时屏幕四周会有一圈荧光提示；
  没有这个权限协助照样能用，只是长辈看不到那圈提示）
- **麦克风**：允许（双向语音；没有它视频和操作都正常，只是不能通话）

> 小米/澎湃注意：`appops set` 设的悬浮窗权限可能被系统改回 `ignore`，
> 请以「设置 → 应用 → 长辈端 → 其他权限 → 显示悬浮窗」里的开关为准。

> **画质**：首页图标连点 7 次进入「高级信息」，可以切换「流畅 · 720p」与
> 「清晰 · 1280p」。长辈手机走移动网络、丢包较多时，流畅档会更跟手（切换会短暂重连）。

成功后会看到绿色的**「已就绪 · 等待对方连接」**和 6 位**配对码**。

---

## 5. 保活设置（重要）

| 设置 | 位置 | 作用 |
|---|---|---|
| 电池优化 → 无限制 | 设置 → 应用 → 长辈端 → 省电策略 | 防止被系统冻结 |
| 允许自启动 | 应用信息 → 自启动 | 重启后能起来 |
| 允许后台活动 | 应用信息 → 权限 | 同上 |
| 充电时保持唤醒 | 开发者选项 | 长期插电时屏幕/进程稳定 |

小米额外：**不要**用"手机管家"的扫描功能，它会关掉开发者选项。

---

## 6. 已知兼容性问题

| 现象 | 原因 | 处理 |
|---|---|---|
| Shizuku 显示运行中，但 App 一直"正在准备" | Shizuku 13.6.0 的 UserService 在联发科机型上崩溃 | 换 **13.5.4** |
| 安装 APK 报 `INSTALL_FAILED_USER_RESTRICTED` | 小米未开"通过 USB 安装" | 打开该开关，或直接在手机上点安装 |
| 会话几分钟后断开 | 系统冻结了后台进程 | 前台服务 + 电池无限制（见 §5） |
| 重启后无法连接 | Shizuku 未自启 | 见 §3 的说明；必要时让家人重新打开一次 App |
| 画面黑屏、只看到"此页面受系统保护" | 应用设置了 `FLAG_SECURE` | 系统行为，无法绕过 |

## 7. 验收清单

- [ ] Shizuku 首页显示"正在运行"，版本 13.5.4
- [ ] 首页显示绿色「已就绪 · 等待对方连接」并显示 6 位配对码
- [ ] 通知栏有"远程协助"常驻通知
- [ ] 控制端输入配对码后能看到画面、能点击
- [ ] 长辈端切到后台后，控制端画面仍然可用（验证前台服务生效）
- [ ] 控制端点"麦克风"后两端都能听到对方（首次授予录音权限）
- [ ] 控制端打开 App 时，设备卡片显示"长辈刚刚按了求助"
- [ ] 长辈端点"结束协助"后，控制端立即断开

## 8. 给长辈的一句话说明

> "这个 App 开着的时候，我就能看到你的手机、帮你点。屏幕上会出现'正在被协助'，
> 你随时点红色的'结束协助'就行。"
