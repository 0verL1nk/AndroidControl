# Quickstart: 端到端验证手册

**Date**: 2026-10-18

本手册用于在真实设备上验证 M1 目标。每条都有明确的**通过标准**。

## 0. 前置条件

| 项 | 要求 |
|---|---|
| 长辈端设备 | Android 8+，长期插电，连家用 Wi-Fi，已按 `docs/ops/elder-device-setup.md` 部署 |
| 控制端设备 | 你的 Android 手机，可切换蜂窝网络 |
| 节点 | 自建节点（新加坡） `<NODE_PUBLIC_IP>:51820`，`wg0 = 10.66.66.1/24` 已运行 |
| 隧道地址 | 控制端 `10.66.66.2`，长辈端 `10.66.66.3` |
| 端口 | 控制通道 27185，视频通道 27186 |

## 1. 验证隧道

**在控制端手机（WireGuard 已导入 `controller.conf` 并启用）**：

```bash
adb shell ping -c 4 10.66.66.3
```

- 通过标准：4 个包全部返回。
- 失败排查：在服务器执行 `wg show` 看是否有 `latest handshake`。

## 2. 验证长辈端引擎已启动

在服务器上查看隧道对端状态，或直接连控制端口：

```bash
adb shell "echo > /dev/tcp/10.66.66.3/27185" && echo "控制端口可达"
```

- 通过标准：端口可建连（此时长辈端应显示"正在被协助"或"已就绪"）。

## 3. 验证画面（US1 前半）

1. 控制端打开控制端 App，选择"爸爸的手机"。
2. 观察画面出现时间。

- 通过标准：**30 秒内出现实时画面**（SC-001）。
- 记录：连续 5 次，记录每次耗时。

## 4. 验证操作（US1 后半）

| 动作 | 操作 | 通过标准 |
|---|---|---|
| 点击 | 点长辈端桌面上的应用图标 | 应用被打开，响应 ≤500ms |
| 滑动 | 在设置列表中向上滑 | 列表滚动，与本地手感一致 |
| 长按 | 长按桌面空白处 | 弹出壁纸菜单 |
| 返回 | 点悬浮栏"返回" | 返回上一级 |
| 主页 | 点悬浮栏"主页" | 回到桌面 |
| 最近任务 | 点悬浮栏"最近任务" | 出现多任务界面 |

## 5. 验证零操作（US2）

1. **重启长辈端手机，全程不碰它。**
2. 等 60 秒。
3. 控制端尝试连接。

- 通过标准：连接成功。连续 10 次，**至少 9 次成功**（SC-004）。
- 记录：失败次数与现象（Shizuku 未自启？引擎未拉起？WireGuard 未连？）。

## 6. 验证安全（US3）

| 场景 | 操作 | 通过标准 |
|---|---|---|
| 未绑定设备 | 用另一台手机（未绑定）连接 | 被拒绝，长辈端有记录 |
| 吊销 | 长辈端移除绑定后，原控制端连接 | 被拒绝 |
| 结束 | 长辈端点"结束" | 控制端画面停止，操作无效 |
| 落盘检查 | 两端搜索最近文件 | 无屏幕内容文件 |

## 7. 验证弱网（US4）

1. 会话进行中，控制端开启飞行模式 30 秒后关闭。
2. 观察恢复时间。

- 通过标准：**20 秒内自动恢复**（SC-006），连续 10 次至少 8 次成功。

## 9. 稳定性（SC-007）

- 连续会话 30 分钟：中途执行若干次滑动与切换应用。
- 通过标准：无崩溃、无不可恢复断流。
